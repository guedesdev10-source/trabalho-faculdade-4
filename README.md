# 🌱 IrrigaSmart

Projeto acadêmico desenvolvido durante o curso de Engenharia de Software.

## 📌 Sobre o projeto

O IrrigaSmart é um sistema desenvolvido com o objetivo de auxiliar no
monitoramento e gerenciamento inteligente de áreas de irrigação.

O projeto busca utilizar tecnologia para facilitar o acompanhamento das
áreas monitoradas e melhorar o controle das atividades relacionadas à
irrigação.

## 🎯 Objetivo

Desenvolver uma aplicação web capaz de apresentar informações de
monitoramento de forma organizada, permitindo uma melhor visualização
e gerenciamento das áreas de irrigação.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- HTML
- CSS
- Vite
